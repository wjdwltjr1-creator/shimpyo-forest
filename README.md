# 쉼표숲

누구나 잠깐 쉬어 가는 온라인 숲. 가입 없이 들어와 귀여운 캐릭터로 앉아 있고, 다른 사람과 조용히 이야기할 수 있어요.

- 공간 3곳: 달빛 호숫가 · 모닥불 언덕 · 빗소리 다락방
- 숨 고르기(4초 들이쉬기·4초 멈춤·6초 내쉬기 3번), 풍경 울리기, 소원 등불 띄우기, 인사하기
- 실시간 접속자 수, 채팅(욕설·연락처 자동 가림, 신고 2~3번이면 10분 말하기 멈춤)
- 옷장: 승복·고무신(기본 무료), 귀도리·털모자(100원, 결제 준비 중)
- 잔잔한 배경 소리(코드로 만든 소리, 켜기/끄기·크기 조절)
- 휴대폰 홈 화면에 앱처럼 설치 가능
- 개인정보 수집 없음: 이름·연락처·위치·IP를 저장하지 않고, 대화는 서버 메모리에 최근 40개만 잠깐 남음

## 실행

```
npm install
npm start          # http://localhost:3000
npm test           # 서버가 켜진 상태에서 두 사람 시험
node test/two-clients.js https://배포주소   # 배포본 시험
```

## 결제 붙일 때 (나중에)
`server.js`의 `validOutfit()`이 지금은 가격 0인 아이템만 허용한다. 결제를 붙이면 구매 기록을 확인해 유료 아이템도 허용하도록 바꾼다.
